# Portfolio Case Study — AXIOM Analytics

> **Status:** In progress. This document is a case-study template; no business outcomes or performance improvements are claimed before measurement.

## Project overview
**Role:** SQL / Data / Systems Analyst (independent portfolio project)  
**Domain:** Fictional e-commerce marketplace  
**Duration:** November–December 2026 (planned 30-day MVP)  
**Data:** Deterministically generated synthetic data, not real customer information.

## Problem
A fictional retail organization lacks consistent metrics across order, payment, refund and marketing data. Analysts need to establish trustworthy KPI definitions and reproducible reporting.

## Approach
1. Gather and prioritize business questions and acceptance criteria.
2. Design a normalized PostgreSQL schema and document relationships.
3. Generate and validate synthetic operational records.
4. Build advanced SQL analyses and reconcile business KPIs.
5. Automate local data loading and validation with Python.
6. Publish BI dashboards and a decision-focused analytical report.

## Technical stack
PostgreSQL, SQL, Python, Metabase, Docker, Mermaid, GitHub.
